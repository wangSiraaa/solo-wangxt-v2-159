# Polyrhythm Lab — 复节奏音序器

在浏览器里比较不同拍长轨道叠加后的节奏。Svelte 5 + TypeScript + Tone.js，纯前端，无服务器，不联网。

## 运行

```bash
npm install
npm run dev      # 开发
npm run test     # 核心逻辑单测（对齐 LCM / 时间换算 / 概率可复现）
npm run check    # 类型检查
npm run build    # 生产构建
```

## 设计要点

### 单一时钟，杜绝错拍
- 全应用唯一时钟是 `Tone.Transport`（AudioContext 时钟 + lookahead 调度）。
- 每条轨道一个 `scheduleRepeat`，间隔用 **tick**（PPQ=192）表示（`"192i"` 记法），
  改 BPM 后所有轨道仍按音乐时间对齐。
- **没有任何 `setInterval`**。网格游标由 rAF 每帧直接读 `transport.ticks`
  换算步号，与音频事件共用同一时钟源，天然一致。

### 统一的音乐时间 ↔ 秒换算
- `src/lib/engine/musicTime.ts` 是唯一换算点：`ticks ↔ beats ↔ seconds(bpm)`。
- 细分单位（四分/八分/三连音…）映射为整数 tick，三连音也整除，无浮点漂移。

### 轨道
- 每条轨道独立的**循环步数**（1–64）与**细分单位**（1m … 32t）。
- 每步：开关、力度（0–1）、触发概率（0–1）。
- 静音 / 独奏（有独奏时仅独奏轨发声）。
- 播放中改步数/细分会**无缝重挂调度**：从当前 transport 位置的下一个步边界
  重新 `scheduleRepeat`，不打断播放。

### 可复现概率
- 不用有状态 PRNG 流，而是 `hash(seed, 循环遍数, 步号) → [0,1)`。
- 同一 seed 下某遍循环的某一步永远得到同一结果，与何时播放、是否改 tempo、
  是否重新调度无关。seed 在轨道面板上可改。

### 重新对齐时刻
- 全部在整数 tick 域做 LCM：面板显示每条轨道循环长度、全局对齐周期、
  两两对齐周期，以及接下来的对齐点（小节.拍），播放时高亮当前位置。

### 样本
- 内置鼓音色（底鼓/军鼓/踩镲/拍手/嗵鼓/边击）由 Tone.js 合成器**本地合成**，
  无任何网络加载。
- 可从本地导入音频文件：Blob 存 IndexedDB，工程里只存引用
  `{kind:'file', name, hash, size}`。引用缺失时轨道显示"缺失"标记。
- **导出 JSON 只含样本引用**，不含音频数据。

### 持久化
- 工程（含全部轨道/步状态）保存到 IndexedDB，可保存/载入/删除/导出/导入。

### 不自动播放
- `Tone.start()` 只在点击"播放"按钮（用户手势）时调用。

## 预设
1. **三对四 (3:4)** — 4 步四分 对 3 步四分，每 3 小节对齐。
2. **七步循环** — 7 步八分（3.5 拍）对 4/4 网格，每 7 小节对齐；踩镲含 50% 概率步。
3. **极速 (240 BPM)** — 三十二分音符踩镲 + 5 步十六分边击（80% 概率），检验高速调度。

## 操作
- **触发**模式：点击格子开/关。
- **力度 / 概率**模式：在格子内按下并上下拖动设置数值（力度显示为橙色柱，
  概率 <100% 时顶部有绿色条，悬停格子可见精确数值）。
